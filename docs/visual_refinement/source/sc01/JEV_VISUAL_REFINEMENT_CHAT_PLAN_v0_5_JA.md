## 2．短い共通境界

| 項目 | 全段階で維持すること |
|---|---|
| 入力 | 同じKのPTS/sample/pixel、選択frameだけ。全frame追跡なし |
| 候補 | 一lane・一Kのマスク一式。混成採用なし、S/A/B/Cは予想帯 |
| 非同期 | 候補・評価は完了順。適格Qを他候補・診断軸の完了まで待たせない |
| 評価 | Qだけ主採用、A/R/I/Cは診断。0・欠測・無効を区別 |
| 版 | 共通根拠更新で旧winnerも再評価。異版Q比較・差分算出なし |
| 理由 | Decisionに当時の判断、matrixに現採用との差。返されていないJev理由を作らない |
| 表示 | 元Kへの重畳、手動閲覧と主採用を分離、固定lane行、E0/E1別系列 |
| queue | unit/scope、待機/実行/終端、最古待機null、active長期化、鮮度を区別 |
| 証拠 | fixture/実mask/実Jev/Replay/commit/UIreceiptを分離 |
| 保存 | 新側のみ。全候補・失敗も保存、旧.env・旧DB・元アプリへ波及なし |
| 対象外 | 自由なスレッド/アーキテクチャ編集UI、P2、OCR/VLM、Jev後追加認識、自動job剪定 |
